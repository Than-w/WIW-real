# wiw

เว็บไซต์ wiw แบบ Static HTML พร้อมเผยแพร่ด้วย GitHub Pages

## ไฟล์ในโปรเจกต์
- `index.html` — หน้าเว็บหลัก รวม CSS และ JavaScript ไว้ในไฟล์เดียว

## วิธีอัปโหลดขึ้น GitHub
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลด `index.html` ไปไว้ที่โฟลเดอร์หลัก (root) ของ Repository
3. เปิด **Settings → Pages**
4. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch `main` และโฟลเดอร์ `/(root)` แล้วกด **Save**
6. รอ GitHub Pages เผยแพร่เว็บ แล้วเปิด URL ที่ GitHub แสดงให้

## หมายเหตุ
- โปรเจกต์นี้เป็น Static Site ไม่ต้องติดตั้งแพ็กเกจหรือมีขั้นตอน build
- Google Fonts โหลดจากอินเทอร์เน็ต หากออฟไลน์อาจใช้ฟอนต์สำรองแทน
- ข้อมูลโพสต์ ความคิดเห็น การกดถูกใจ และการตั้งค่าถูกเก็บใน `localStorage` ของเบราว์เซอร์แต่ละเครื่อง จึง **ไม่ได้ซิงก์ระหว่างผู้ใช้** และการล้างข้อมูลเบราว์เซอร์อาจทำให้ข้อมูลหาย
- การอัปโหลดรูปในหน้าเว็บเป็นการเก็บข้อมูลรูปในเบราว์เซอร์ ไม่ได้อัปโหลดไปเก็บบน GitHub หรือเซิร์ฟเวอร์กลาง
